Real-Debrid

From real-debrid.com/apitoken. Stored in plain text in the plugin's configuration file, like every other Jellyfin plugin credential.
How this server is reached, for example http://192.168.1.10:8096. Every library item points here, so it must be reachable by your players as well as by the server itself.
How many of the newest torrents to take. 0 means the whole account. A first pass costs roughly one API call per torrent.
Real-Debrid publishes 250 requests per minute and counts refused ones against the allowance, so 300 ms leaves headroom. Lower it only if you know why.

Libraries

Movies and shows need separate libraries. Jellyfin chooses metadata providers by library type, and both are created for you on the first sync.
One entry per film with the releases behind it as selectable versions, instead of the same film listed twenty times. Byte-identical re-adds are always dropped.
Deletes library entries whose torrent no longer exists in the account. Leave this off if you want a deleted torrent to keep its entry until you clean it up yourself.
Real-Debrid often serves a release as a RAR without saying so: the file list claims X.mkv and the link serves X.mkv.rar. With this on, a stored archive is read through and the file inside is served. With it off, such releases are left out rather than added as items that will not play.
