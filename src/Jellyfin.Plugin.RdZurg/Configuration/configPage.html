Real-Debrid

From real-debrid.com/apitoken. Use the private API token. OAuth access tokens expire and are not refreshed by this plugin.
How this server is reached, for example http://192.168.1.10:8096. Every library item points here, so it must be reachable by your players as well as by the server itself.
How many of the newest torrents to take. 0 means the whole account. A first pass costs roughly one API call per torrent. A limited sync preserves existing entries; removal requires a complete account sync (0).
Real-Debrid publishes 250 requests per minute and counts refused ones against the allowance, so at least 300 ms is required. Link generation also has a separate five-second interval.

Libraries

Movies and shows need separate libraries. Jellyfin chooses metadata providers by library type, and both are created for you on the first sync. These names apply when creating libraries. Rename existing libraries in Jellyfin’s library settings.
One entry per film with the releases behind it as selectable versions, instead of the same film listed twenty times. Byte-identical re-adds are always dropped.
After a complete account sync, deletes entries whose torrent no longer exists. Leave this off if you want a deleted torrent to keep its entry until you clean it up yourself.
Real-Debrid often serves a release as a RAR without saying so: the file list claims X.mkv and the link serves X.mkv.rar. With this on, a stored archive is read through and the file inside is served. With it off, archive playback returns a controlled error. Unsupported archives can still appear in the library because checking every file during sync would require many extra provider calls.
Leave off for remote players: the server streams all media through its own connection. Enable only when players and the server share the same public internet address. Archives always stream through the server.
